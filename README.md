**VirtualCollege** — дипломный VR-проект на **Unity** для знакомства с колледжем и прохождения интерактивных практических заданий в виртуальной среде.

Пользователь проходит авторизацию, выбирает специальность, знакомится с локацией через обучение, взаимодействует с NPC и выполняет профильные квесты в формате VR-тренажёра. Проект использует **Meta XR SDK**, **OpenXR**, **URP** и подключение к внешнему backend API для профиля, прогресса и достижений.

---

## 🎮 Основные возможности

### Пользовательский сценарий

- 🔐 **Авторизация и регистрация** — вход в систему, создание аккаунта и выбор специальности.
- 👤 **Гостевой режим** — отдельная сцена для запуска без авторизации.
- 🗂 **Панели профиля** — после обучения доступны профиль, журнал квестов и достижения.

### NPC и прогресс

- 🧭 **Обучение** — пошаговое знакомство с проектом через куратора и другие точки маршрута.
- 🗣 **Диалоги с NPC** — запуск стартовых, промежуточных и завершающих реплик.
- ✅ **Состояния квестов** — получение задания, выполнение, повторный диалог и завершение.
- 🏆 **Достижения** — загрузка и отображение достижений из профиля пользователя.
- ☁️ **Синхронизация с API** — прогресс, профиль и обучение подтягиваются с сервера.

### Практические VR-задания

- 💻 **Информационные системы и программирование** — сборка компонентов ПК, работа с серверным оборудованием и диагностика.
- 🍳 **Поваркое и кондитерское дело** — сортировка ингредиентов, работа с последовательностью предметов и выдача блюда.
- 📦 **Материально‑техническое обеспечение** — перенос коробок, размещение объектов и сканирование предметов.

### Взаимодействие

- ✋ **Захват предметов** — интерактивные объекты можно брать и использовать в заданиях.
- 🎯 **Подсветка целей** — активные зоны и нужные предметы визуально выделяются во время квестов.
- 🎮 **Контроллерный ввод** — взаимодействие и открытие HUD выполняются через VR-контроллеры.

## 🕹 Как использовать

1. Запустите сцену **AuthScene**.
2. Войдите в аккаунт или зарегистрируйте нового пользователя.
3. Выберите специальность при регистрации.
4. После входа откроется основная VR-сцена колледжа.
5. Пройдите обучение через NPC онбординга.
6. Взаимодействуйте с профильными NPC и берите задания.
7. Выполняйте VR-задачи по своей специальности.
8. После завершения обучения открывайте профиль, журнал квестов и достижения.

---

## 🚀 Запуск проекта

1. Склонируйте репозиторий:

```bash
git clone https://github.com/qwertynoqwerty/VRCollegeVR.git
```

2. Откройте проект в **Unity 6**.
   Проверенная версия проекта: **6000.0.62f1**.
3. Дождитесь импорта пакетов и ассетов.
4. Убедитесь, что установлены зависимости XR и Android Build Support.
5. Откройте сцену - **AuthScene**;
6. Нажмите **Play**.
